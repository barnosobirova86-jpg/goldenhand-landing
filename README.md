# Golden Hand — اليد الذهبية للعناية بالسيارات

Landing page for Golden Hand car care, Benghazi (XPEL PPF, PDR, Nano Ceramic, Polish).

Live: https://goldenhandcarcare.ly

- Static site: `index.html`, `styles.css`, `app.js`
- Content (Arabic / English): `data.js` (business info, products, services, centers) and `i18n.js` (UI text)
- Hosted on Cloudflare Workers (`dark-sun-7536`); domain registered at Libyan Spider.

Run locally: `python -m http.server 5500` and open http://localhost:5500
